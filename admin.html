Pannello di gestione

Accedi con GitHub

Le modifiche vengono salvate direttamente nel repository del sito (un commit), e il sito si aggiorna da solo in uno o due minuti. Possono farlo solo i componenti con permesso di scrittura sul repository: per entrare serve un token personale di GitHub, che resta nel tuo browser e non viene mai salvato nel sito.

Non verrà mostrato né salvato, a meno che tu non scelga di ricordarlo qui sotto.

Come creo il token?
  1. Su GitHub vai in Settings → Developer settings → Personal access tokens → Fine-grained tokens e scegli Generate new token.
  2. Repository access: Only select repositories e scegli solo il repository del sito.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Imposta una scadenza breve (per esempio 30 giorni), genera il token e incollalo qui sopra.

Non condividere il token con nessuno: chi lo ha può modificare il repository.
